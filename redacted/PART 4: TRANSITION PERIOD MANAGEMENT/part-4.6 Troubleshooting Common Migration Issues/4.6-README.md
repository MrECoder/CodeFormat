
Issue 1: "Could not resolve dependencies"
[ERROR] Failed to execute goal on project common-java-components: 
Could not resolve dependencies for project redacted.group.id:common-java-components:jar:${revision}${changelist}
Solution:

Flatten plugin not configured correctly
Add flatten plugin to <build><plugins> section
Ensure it runs before other plugins


Issue 2: "Unresolved property in deployed POM"
Nexus POM still shows ${revision}${changelist}.
Solution:
xml<!-- Ensure flatten plugin configuration -->
<plugin>
    <groupId>org.codehaus.mojo</groupId>
    <artifactId>flatten-maven-plugin</artifactId>
    <configuration>
        <updatePomFile>true</updatePomFile>
        <flattenMode>resolveCiFriendliesOnly</flattenMode>
    </configuration>
</plugin>


Issue 3: "Local build works, CI fails"
Solution:

Check that CI passes -Drevision and -Dchangelist
Verify GitLab CI environment variables are set
Check Maven options in CI: MAVEN_OPTS and MAVEN_CLI_OPTS


Issue 4: "Parent POM not found"
[ERROR] Non-resolvable parent POM for redacted.group.id:common-java-components:
Could not find artifact redacted.group.id:redacted-parent:pom:${revision}${changelist}
Solution:

Parent POM not deployed with flattened version
Deploy parent-pom first: mvn clean deploy -Drevision=0.0.1 -Dchangelist=-SNAPSHOT
Check Nexus has the artifact
