4.4 Rollback Plan
If critical issues arise during migration:
Immediate Rollback (within 24 hours):
bash# Revert parent-pom repository
cd parent-pom-repo
git revert <commit-sha-of-migration>
git push origin main

# Redeploy old versions
mvn clean deploy
Partial Rollback (component-specific):
bash# Revert specific component
cd common-java-components
git revert <commit-sha>
git push origin main
mvn clean deploy
Complete Rollback (after 1+ week):
bash# Use backup directory from migration script
cd pom-backups-YYYYMMDD-HHMMSS

# Restore each POM
cp bom/pom.xml ../../bom/
cp parent/pom.xml ../../parent/
# ... etc

# Commit and deploy
git add .
git commit -m "Rollback CI-friendly version migration"
git push
mvn clean deploy
