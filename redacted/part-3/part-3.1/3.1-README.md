3.1 Nexus Snapshot Repository Configuration
Access your Nexus instance at https://nexus.electra.lan and configure the snapshot repository:
Step 1: Configure Snapshot Repository Policy

Login to Nexus as administrator
Navigate to: Administration → Repository → Repositories
Select your snapshot repository (likely named redacted based on your POM)
Click Edit

Configure these settings:
yamlRepository Type: Maven2 (hosted)
Version Policy: Snapshot
Layout Policy: Strict

Deployment Policy: Allow Redeploy
  ↳ This is CRITICAL - allows overwriting SNAPSHOTs

Storage:
  Blob Store: default (or your custom blob store)
  Strict Content Type Validation: Enabled

Cleanup Policies:
  - Create new policy: "snapshot-cleanup-30days"
    Format: maven2
    Criteria:
      - Last Downloaded: 30 days
      - Asset Regex: .*-SNAPSHOT.*
    
Hosted:
  Deployment Policy: Allow Redeploy
  Proprietary Components: Enabled
Step 2: Create Release Repository (if not exists)
yamlRepository Type: Maven2 (hosted)
Name: redacted-releases
Version Policy: Release
Layout Policy: Strict

Deployment Policy: Disable Redeploy
  ↳ Prevents overwriting release artifacts

Storage:
  Blob Store: default
  Strict Content Type Validation: Enabled

Cleanup Policies: None (or conservative retention)
